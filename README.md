## 💻 Tech Stack
- **Framework:** Flutter / Dart
- **State Management & Routing:** GetX 
- **Backend:** Firebase Auth, Cloud Firestore
- **Architecture:** Feature-first folder structure

## ✨ Features
- **Khách hàng:** Trải nghiệm đặt vé mượt mà, chọn ghế real-time, sinh vé điện tử mã QR, tự động tạo thông báo, hủy vé trước 2 tiếng.
- **Admin:** Dashboard tổng quan, CRUD chuyến xe, quản lý trạng thái đơn đặt vé (Đang chờ, Hoàn thành, Đã hủy).
